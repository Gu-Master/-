# 万劫 — starter 0.1

Стартовый каркас проекта: существующая карта оставлена клиентом, добавлен отдельный Node.js HTTP-сервер и API карты.

## Требования
- Node.js 20 или новее
- Git (если работаешь через GitHub)

## Запуск локально
```bash
npm run dev
```
Открой http://127.0.0.1:3000

Проверки:
- http://127.0.0.1:3000/api/health
- http://127.0.0.1:3000/api/map

## Структура
```text
client/public/index.html   текущая живая карта
server/src/index.js        HTTP-сервер и API
server/data/world.json     данные демо-региона
shared/world.schema.json  контракт данных карты
```

## Подключение карты к серверу
В карте есть блок «Источник данных». Адрес `http://localhost:3000` уже задан.
Нажми «Подключить». Сервер отдаёт `/api/map` в формате, который карта ожидает.

## GitHub Codespaces
1. Создай пустой репозиторий на GitHub.
2. Загрузи туда содержимое этой папки.
3. На странице репозитория нажми **Code → Codespaces → Create codespace**.
4. В терминале Codespaces выполни `npm run dev`.
5. Вкладка **Ports** покажет порт 3000 — открой его через **Open in Browser**.

Для Codespaces сервер должен слушать `0.0.0.0`, а не только `127.0.0.1`.
В настройках Codespaces перед запуском используй:
```bash
HOST=0.0.0.0 npm run dev
```
В Windows PowerShell:
```powershell
$env:HOST="0.0.0.0"; npm run dev
```

## Важное
Это стартовый каркас, не полноценная симуляция. Пока сервер отдаёт карту и health-check.
Состояние NPC, события, экономика, сохранения и авторитетная серверная симуляция ещё не реализованы.
Не добавляй игровую логику в HTML дальше: новые системы постепенно переносим в `server/src`.
